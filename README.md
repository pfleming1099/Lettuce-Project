**Let Shapes: Simple coding language**  

Implements simple coding language allowing arithmetic and boolean operations and creation/manipulation of 2D geometry. Built in Scala.

**Main Components**  

Expressions (expr): numbers, booleans, identifiers, arithmetic, logic, functions, shapes.  
Values (value): the result of evaluated expressions.  
Environment (env): tracks bindings during evaluations.  

**Features Implemented**  

Numeric Operations (Plus, Minus, Mult, Div)  
Boolean Operations (And, Or, Not)  
Comparisons (Eq, Neq, Gt, Geq)  
Function definitions, funciton calls, and recursion  
Figure Primitives and operations with said figures  

**How to Run**  

with Scala and sbt installed compile and run with 'sbt compile' and 'sbt run', then enter the desired test and view output.png. Test code is available in the directory to see the language as written.
